# Vibe Popup

Простой попап без зависимостей, с лёгкой анимацией появления и исчезания. Подходит для статей, карточек, форм: всё, что нужно показать поверх страницы.

Демо: https://ivanmayorov.github.io/vibe-popup/

Вырос из попапа проекта Rocket и попапа статей на сайте курса «Вайбдизайнер».

## Что умеет

- Прокрутка не застревает: если внутри окна есть блок со своим скроллом, после его конца колесо крутит дальше само окно.
- Крестик едет вместе с прокруткой, поэтому закрыть окно можно с любого места длинного текста.
- Закрывается крестиком, клавишей Esc, кликом по фону и любым элементом с атрибутом `data-vibe-popup-close`.
- Внутри окна нет своего скролла. Окно растёт вместе с содержимым и уходит за нижний край экрана, так видно, что дальше есть ещё текст. Прокручивается слой с попапом целиком, как обычная страница.
- Пока попап открыт, сайт под ним недоступен и стоит на месте. Пропавшая полоса прокрутки заменяется таким же отступом справа, поэтому сайт не прыгает. Ширина полосы лежит в переменной `--vibe-popup-scrollbar`: её можно добавить фиксированной шапке (`padding-right: var(--vibe-popup-scrollbar, 0px)`).
- Попапы можно открывать друг поверх друга: нижний чуть уменьшается и отходит назад, верхний поднимается снизу и быстро проявляется. Esc закрывает верхний.
- После закрытия фокус возвращается на кнопку, которая открыла попап.
- Появляется за 180 мс и исчезает за 120 мс. Если в системе включено «Уменьшить движение», анимации нет.
- На телефоне открывается шторкой снизу: короткое окно занимает высоту по содержимому, длинное начинается чуть ниже верха экрана и прокручивается.
- Светлая и тёмная тема, цвета и размеры меняются через CSS-переменные.

## Как подключить

```html
<link rel="stylesheet" href="vibe-popup.css">
<script src="vibe-popup.js"></script>
<script>
  const p = VibePopup.open({
    content: "<h2>Привет</h2><p>Любой HTML или DOM-элемент</p>",
    label: "Привет",       // название окна для экранных дикторов
    wide: false,           // true — широкое окно, например для схем
    onClose() { /* что сделать после закрытия */ },
  });
  // p.close() — закрыть из кода, VibePopup.closeAll() — закрыть все
</script>
```

Пример лежит в `index.html`: откройте его в браузере.

## Как попросить агента

## Настройка

Переопределите переменные в своём CSS:

```css
:root {
  --vibe-popup-bg: #fff;
  --vibe-popup-radius: 20px;
  --vibe-popup-width: 800px;
  --vibe-popup-shade: rgb(26 28 33 / 0.5);
}
```
